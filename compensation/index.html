What happened

  • 21 Oct 2026, 07:58:54 UTC — An unrelated wallet uploaded a malicious contract code (code 11735). Store-code tx
  • 07:59:06 UTC — The same wallet called migrate_staking on Garuda's staking factory. All 9 staking contracts were migrated to the malicious code and every balance was swept to the attacker's wallet in one transaction. Sweep tx
  • 08:01:17 UTC — The attacker sold all 2,424.316273 FUN taken from this pool for ~26,880,974 LUNC. Sale tx
  • Drained FUN pool contract: terra1n9sfyjsnzjpshn7rq3xxh43p3m0khg65urge4ypflxsdk8d5jx7svz0lu7 · Attacker wallet: terra10ytpt4g5j3c0rmg2qlr6nyryqclcff87elszm6 (not a Garuda wallet — the factory let a wallet with no Garuda role migrate every staking contract).

How this was verified

The malicious code has no query functions, but it did not wipe the contract's storage. The contract's raw on-chain state was read after the attack; its stake records (wallet, amount, dates) survived intact.

Reconciled exactly: stakers' principal 2,360.474154 FUN + FUN rewards pool 63.842119 FUN = 2,424.316273 FUN — precisely what the sweep transaction took from this contract. Difference: 0.

Not included above: rewards that had accrued but not yet been claimed in the pool's ~36 cross-reward tokens. Those accrue per-staker from shared pools and cannot be split per wallet from balances alone; the surviving contract state holds the pool rates and last-withdraw timestamps needed to compute them.

Where FUN staking lives now

A replacement FUN staking app — built so an outsider cannot migrate or drain it the way the Garuda factory allowed — is live: lunc-projects.github.io/fun-rewards. This ledger is only the record of the old Garuda pool; it does not move funds and is not a claim portal. Any compensation decision and funding rest with the Garuda and FUN teams.
